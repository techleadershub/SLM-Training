# Final: all labs for the 3-day SLM training

This folder holds the final, consolidated course code: Day 1, Day 2 and Day 3 notebooks (plus four optional extra labs), the helper files they import, and the data. Start with `START_HERE.md`.

It is the same content as the full zip, **without the two prepared adapters** (74 MB each; they are only a fallback if your own training fails).

**Full zip with the adapters:** download `SLM-Training-All-Days.zip` from the [Releases page](https://github.com/techleadershub/SLM-Training/releases/tag/all-days).

The older zips in the main folder of this repository (`SLM-Training-Code.zip`, `SLM-Training-Day2.zip`, `SLM-Training-Day3-no-adapters.zip`) are superseded by this folder.
